# Как восстановить контекст проекта

Этот документ предназначен для владельца проекта, если новый чат или новый AI-ассистент не знает историю AiPayWorlds.

## Самый простой способ

1. Откройте файл `docs/AI_CONTEXT.md` в репозитории.
2. Скопируйте его содержимое.
3. Вставьте в новый чат.
4. Добавьте инструкцию ниже.

## Текст для нового чата

> **ВОССТАНОВЛЕНИЕ КОНТЕКСТА AIPAYWORLDS**
>
> Ниже передан текущий `docs/AI_CONTEXT.md`.
>
> Сначала восстанови контекст проекта. Ничего не меняй и не предпринимай действий.
>
> После чтения:
> 1. кратко перечисли миссию и текущую фазу;
> 2. перечисли утверждённые решения;
> 3. перечисли гипотезы, которые ещё не утверждены;
> 4. перечисли известные ограничения и риски;
> 5. перечисли открытые вопросы;
> 6. определи следующий шаг;
> 7. укажи, какой информации тебе не хватает;
> 8. отдельно отметь любые противоречия между переданным контекстом и текущими файлами, если ты получил доступ к репозиторию.
>
> Не выдумывай отсутствующий контекст. Если данные противоречат друг другу, остановись и попроси подтвердить правильную версию.
>
> Не принимай новых архитектурных, финансовых, юридических или security-решений до завершения восстановления.

## Если доступен весь репозиторий

Перед продолжением дополнительно прочитайте:

- `docs/PROJECT_RULES.md`
- `docs/PROJECT_STATE.md`
- `docs/DECISIONS.md`
- `docs/ROADMAP.md`
- `docs/RESEARCH.md`
- `docs/ARCHITECTURE.md`
- `docs/SECURITY.md`

Затем проверьте Git history и последние изменения.

## Когда обновлять память

Обновляйте `AI_CONTEXT.md` после каждого существенного milestone, архитектурного решения или изменения текущего состояния. Перед публичным testnet/mainnet и другими необратимыми действиями создавайте обязательный checkpoint.

## Важное правило

`AI_CONTEXT.md` — это текущий снимок, а не единственный источник истины. Полная история находится в документации, Git history, коде, тестах и релизах.
