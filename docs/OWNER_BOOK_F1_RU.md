# Книга владельца — F1 Dashboard Foundation

**Статус:** ACTIVE  
**Язык:** Русский  
**Английский режим:** доступен в приложении  
**Цель:** научить Owner понимать и безопасно управлять фундаментом AiPayWorlds OS.

## Как пользоваться книгой

Каждый учебный раздел имеет четыре уровня:

1. **Понять** — простое объяснение без предположения о знаниях программирования.
2. **Увидеть** — что именно происходит в Dashboard.
3. **Сделать** — безопасная практическая операция.
4. **Проверить** — как убедиться, что результат правильный.

После каждого уровня сохраняется прогресс локально.

## F1.1 — Что такое AiPayWorlds OS

Изучаем:
- чем desktop application отличается от сайта;
- что такое frontend и backend;
- зачем нужен локальный runtime;
- почему приложение может работать без интернета.

Практика:
- запустить приложение;
- отключить сеть;
- убедиться, что основное UI продолжает работать.

## F1.2 — Навигация и модули

Изучаем:
- module registry;
- navigation state;
- разделы проекта;
- скрытые и будущие модули;
- архивирование модулей без удаления архитектуры.

## F1.3 — Языки RU / EN

Изучаем:
- localization;
- locale;
- translation keys;
- fallback;
- почему текст нельзя дублировать вручную в каждом компоненте.

## F1.4 — Темы и визуальная система

Изучаем:
- design tokens;
- theme;
- typography;
- spacing;
- accessibility;
- контраст.

Практика:
- переключить несколько тем;
- проверить, что состояние проекта не изменилось.

## F1.5 — Animation Budget

Изучаем:
- FPS;
- frame time;
- GPU load;
- animation budget;
- LOD;
- почему больше эффектов не всегда означает лучше.

Практика:
- сравнить Off / Low / Medium / High / Cinematic;
- найти режим, который комфортен на локальном ПК.

## F1.6 — Earth Engine

Изучаем:
- 3D-сцена;
- камера;
- освещение;
- положение Солнца;
- терминатор день/ночь;
- локальные Earth assets;
- будущие blockchain layers.

Важно:
- базовое освещение и время вычисляются локально;
- онлайн-данные не должны быть обязательными для запуска.

## F1.7 — Offline-first

Изучаем:
- offline-first;
- cache;
- local state;
- LAST KNOWN;
- network adapter;
- graceful degradation.

Практика:
- запустить приложение без сети;
- проверить локальные книги и Earth Engine;
- затем включить сеть и увидеть безопасную синхронизацию.

## F1.8 — Security Boundary

Изучаем:
- sandbox;
- IPC;
- permissions;
- capabilities;
- scopes;
- почему frontend не должен иметь полный доступ к компьютеру.

## F1.9 — Git и состояние проекта

Изучаем:
- repository;
- branch;
- commit;
- working tree;
- checkpoint;
- Source of Truth.

Практика:
- прочитать статус проекта через Dashboard;
- понять разницу между локальным состоянием и GitHub.

## F1.10 — Recovery

Изучаем:
- AI_CONTEXT;
- PROJECT_STATE;
- DECISIONS;
- SESSION_LOG;
- recovery contract;
- drift.

Цель:
Owner должен понимать, почему новый чат может восстановить проект без скрытой памяти конкретной модели.

## F1.11 — Private operator application

Изучаем:
- зачем публичному проекту отдельный private application repository;
- что может быть public;
- что должно оставаться private;
- почему `.gitignore` не является заменой приватному хранилищу.

## F1.12 — F1 checkpoint

Owner должен уметь объяснить своими словами:

- что такое AiPayWorlds OS;
- почему приложение desktop;
- почему оно offline-first;
- зачем нужны RU/EN;
- зачем Earth Engine;
- что такое module registry;
- что такое capability/permission;
- чем public repo отличается от private operator repo;
- почему blockchain и token пока не считаются утверждёнными.
